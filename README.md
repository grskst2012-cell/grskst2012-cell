# flm0110

Student. I write Android apps in Kotlin and Jetpack Compose, mostly for hardware I own: a watch, a 3D printer, smart glasses. All projects are MIT-licensed, with APK releases and Russian/English READMEs where noted.

## Projects

| Project | What it does | Download |
|---|---|---|
| [Wear VPN](https://github.com/grskst2012-cell/WearVpn) | VLESS/Xray VPN and proxy client for Wear OS 3+; falls back to proxy mode on watches without a system VPN (Pixel Watch 4). Imports subscription URLs. | [APK](https://github.com/grskst2012-cell/WearVpn/releases/latest) |
| [Printer Remote](https://github.com/grskst2012-cell/FlashForgeRemote) | Local-network remote for 3D printers: FlashForge, Klipper/Moonraker, OctoPrint. No cloud, no account. Two themes (Nothing-style, Material 3). | [APK](https://github.com/grskst2012-cell/FlashForgeRemote/releases/latest) |
| [Meta Mockup](https://github.com/grskst2012-cell/meta-mockup) | Russian/English voice assistant for Bluetooth smart glasses; answers come from named sources (weather, exchange rates, Wikipedia, web search). | [APK](https://github.com/grskst2012-cell/meta-mockup/releases/latest) |

Status of each project (what is verified on real hardware and what is not) is stated at the top of its README.
